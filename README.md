# Digital Wedding Invitation

A beautiful, modern, and interactive digital wedding invitation created for SreeLakshmi P & Sanesh K. This web-based invitation features an elegant dark-themed "Lavender" aesthetic with smooth animations and glassmorphism UI elements.

## Features

- **Elegant Design:** A sophisticated dark theme with a curated lavender color palette and modern typography (`Cormorant Garamond` and `Great Vibes`).
- **Interactive Animations:** Features a dynamic "Falling Flowers" canvas background and subtle scroll-triggered fade-in animations for a premium feel.
- **Live Countdown:** A real-time countdown timer tracking days, hours, minutes, and seconds until the special day (August 23, 2026).
- **Event Timeline:** A beautifully structured vertical timeline detailing the schedule for the Wedding Eve and the main Wedding Ceremony.
- **Venue & Location:** Clear venue details with a direct integration to Google Maps for easy navigation.
- **Responsive Layout:** Fully optimized for all devices, from desktop monitors to mobile phones.

## Technologies Used

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom properties (variables), Flexbox/Grid, CSS animations, and glassmorphism effects.
- **JavaScript (ES6+):** Logic for the countdown timer and canvas animations.
- **Vite:** Next-generation frontend tooling for a fast and optimized development experience.
