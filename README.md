# MangaLens — Manga Translator Extension

A powerful and free Chrome extension for translating manga panels directly in your browser, with multi-language support. MangaLens uses the free OCR.space API for text extraction and MyMemory for translation, meaning no billing or Google Cloud configuration is required!

## Features
- **100% Free**: No credit card required. Uses OCR.space (25,000 free scans/month) and MyMemory (free translation API).
- **Multi-Language Support**: Auto-detects source languages (Japanese, Korean, Chinese, and more) and translates them to English, Spanish, French, German, Portuguese, Arabic, Hindi, or Indonesian.
- **In-Browser Translation**: Translates text directly over the manga panels.
- **Easy to Use**: Clean, aesthetic UI with simple toggles and configuration.

## Installation

Since this extension is not currently on the Chrome Web Store, you can install it manually as an "unpacked extension":

1. Download or clone this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click on **Load unpacked** in the top left corner.
5. Select the folder where you downloaded the code.
6. The extension is now installed! Pin it to your toolbar for easy access.

## How to Use

1. Click on the MangaLens extension icon in your toolbar.
2. Enter your **OCR.space API Key**. You can get a free key [here](https://ocr.space/ocrapi/freekey) by just providing your email.
3. Select your desired Source and Target languages.
4. Navigate to a manga page and click **Translate Page** in the extension popup.
5. Watch the panels get translated automatically!

## Privacy & Data
Your API key is stored locally in your browser using Chrome's secure storage. We do not track your usage or send any data to external servers other than the OCR and Translation APIs necessary for the extension to work.
